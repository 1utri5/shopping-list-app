# 🛒 쇼핑 리스트 앱

순수 HTML/CSS/JavaScript로 만든 간단한 쇼핑 리스트 웹앱입니다. 별도의 빌드나 서버 없이 브라우저에서 바로 실행됩니다.

## 기능

- 항목 추가 (입력 후 `추가` 버튼 또는 Enter)
- 체크박스로 완료 표시 (취소선 처리)
- 항목 개별 삭제
- 완료된 항목 한 번에 비우기
- `localStorage`에 자동 저장 — 새로고침해도 유지
- 완료/전체 개수 카운터

## 실행 방법

`shopping-list.html` 파일을 브라우저로 열기만 하면 됩니다.

## 기술 스택

- HTML, CSS, Vanilla JavaScript
- 브라우저 `localStorage`
